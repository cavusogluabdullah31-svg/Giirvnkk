# CF Loader (no root)
By @xXsylas

Requirements:
- Android 8+
- Shizuku installed + active (Wireless Debugging)
- Overlay permission

Build (PC / Android Studio):
1. Open folder in Android Studio
2. Sync Gradle
3. Run / Build APK

AIDE:
- Import project
- Ensure internet for Maven deps
- Build

Note: set entity base via NativeBridge.setEntityBase(addr) after finding offset.
